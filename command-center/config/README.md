# Configuração

A pasta `config` mantém a customização do primeiro cliente da plataforma separada do núcleo visual e funcional.

- `organization.json`: identidade e empresas do Grupo Maurício.
- `modules.json`: módulos habilitados.
- `permissions.json`: perfis de acesso iniciais.

Essa separação permite evoluir o Command Center OS como produto multi-organização.
